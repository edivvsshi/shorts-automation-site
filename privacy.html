Shorts Automation

Privacy Policy

Last updated: 11 November 2026

Shorts Automation (“the tool”) is a private application used only by the owner of the YouTube channel ed1vvs. It uses YouTube API Services. By interacting with the channel you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

Data the tool accesses

  • The owner's channel (OAuth, granted by the owner): uploading and scheduling the owner's own videos, and reading the channel's basic information.
  • Comments on the channel's own videos: the text, the commenter's channel ID and the time of each top-level comment, read only to count votes (“A” or “B”) for the next episode.
  • View statistics of the channel's own videos (YouTube Data API and YouTube Analytics API): used only to choose the daily publishing time.

How the data is used and stored

  • Vote counting keeps only the totals and a one-way hash of each commenter's channel ID (to enforce one vote per account). Comment texts and real channel IDs are not stored after counting.
  • Results are stored in a private repository controlled by the owner. Authorization tokens are stored as private secrets and are never published.
  • The data is not sold, not shared with third parties and not used for advertising.
  • Shorts Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Vote results are kept as part of the series history while the series is running. The owner can delete them at any time. The access granted to the tool can be revoked at any time from the Google security settings page (Third-party apps & services).

Contact
